# AGENTS.md — 设置与配置

本规则补充根目录 [AGENTS.md](../../../AGENTS.md) 与 [lib/AGENTS.md](../../AGENTS.md)，覆盖设置模块的结构、数据持久化及交互规范。

## Settings & Configuration Rules (Rust)
- **禁止散落读取**：严禁在 `src/settings/manager.rs` 以外的任何地方直接读写 `settings.json` 或为此调用 `std::fs` / `serde_json`。
- **新增配置项流程**：
  1. 必须在 `src/settings/schema.rs` 对应的子结构体中添加字段，并在 `impl Default` 中提供默认值。
  2. 确保结构体带有 `#[serde(default)]` 属性。
  3. 业务代码读取配置必须通过 `SettingsManager::with(|s| ...)`，修改配置必须通过 `SettingsManager::update(|s| ...)`。

## 页面导航与布局结构 (Flutter UI)

设置页采用**全局收窄导航侧栏 + 右侧多级菜单**的设计，与全应用主界面保持一致的空间骨架：

```text
┌─────────────────┬─────────────────────────────────────────────────────────┐
│ AppNavigation   │ 设置主区域                                              │
│ Sidebar         │ ├─ 一级概览卡片页（点击卡片推入二级）                   │
│ (折叠 56 / 展开 180)│ │    [外观]   [通用]   [数据与存储]   [关于]            │
│                 │ ├─ 二级独立设置页（占满右侧区域，非半滑抽屉）           │
│                 │ │    [ < 返回 ] 通用                                    │
│                 │ │    └─ 无小标题选项列表（[语音 >] [屏幕共享 >] [图片上传]）│
│                 │ └─ 三级独立设置页（占满右侧区域，最后一级允许小标题）   │
│                 │        [ < 返回 ] 语音 / 屏幕共享                       │
│                 │        ├─ SettingsSection 带小标题分组卡片              │
│                 │        │    ├─ SettingsTile / SettingsRadioGroup        │
└─────────────────┴─────────────────────────────────────────────────────────┘
```

### 交互规则
1. **多级菜单非抽屉**：点击分类卡片或子项入口后，**直接占满右侧主内容区**进入对应子页面，严禁使用从右侧滑出一半的 SideSheet/Drawer。
2. **面包屑式逐级返回机制**：各级页面顶部提供标准返回按钮（带左箭头）；同时绑定物理按键 `LogicalKeyboardKey.escape`。
   - 三级页面（语音 / 屏幕共享）按返回按钮或 `ESC` 键退回二级通用页面。
   - 二级页面按返回按钮或 `ESC` 键退回一级概览页。
   - 一级概览页按返回按钮或 `ESC` 键退回进入设置页前的页面（来路）；若无历史路由，已连接时退回工作区，未连接时退回首页。
3. **顶栏无冲突拖拽**：桌面端窗口拖拽区域（`WindowDragRegion`）置于各级顶栏的中间空白处，不得遮挡或拦截左侧返回按钮的手势。

## 小标题与排版规则

1. **仅最后一级（三级页面）允许小标题**：
   - **一级概览页**：不允许小标题，直接展示无标题卡片。
   - **二级页面（外观、通用、数据等）**：均不允许小标题，所有设置行或跳转入口均放在无标题卡片中（`generateSection(items: [...])`），禁止出现冗余的分组小标题。
   - **三级页面（通用下的「语音」、「屏幕共享」）**：作为三级也是终端页面，**允许保留分组小标题**（例如「按住说话」、「麦克风」、「默认画质」、「编码与网络策略」）。
2. **标题 + 当前值**：一级分类导航卡片与二级跳转卡片仅展示分类名称与图标，文案垂直居中，不展示深层页面内的具体配置项内容；末级页面内的具体设置项如果属于非选项类设置，才在 `subtitle` 中说明当前生效的取值。选项类设置（如一级置顶的语言设置）通过 `SettingsOptionsTile` 将当前值展示（含 `PopupValueText` 模糊切换动效）置于 `trailing` 按钮中，点击后呼出依附于控件的选项菜单。
3. **界面文案、悬停提示与无障碍名称**：遵守 [Flutter 界面文案与操作按钮约束](../../../docs/defensive-patterns/ui.md)。
4. **合规与命名**：未直接依赖源码的文件中，严禁出现模仿或对齐外部项目的名称字样。

| **语言设置（一级置顶）** | 语言选择 | - | 简体中文 (`zh`) / English (`en`) / 跟随系统 (`null`) |
