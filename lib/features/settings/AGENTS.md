# AGENTS.md — 设置与配置

本规则补充根目录 [AGENTS.md](../../../AGENTS.md) 与 [lib/AGENTS.md](../../AGENTS.md)，覆盖设置模块的结构、数据持久化及交互规范。

## Settings & Configuration Rules (Rust)
- **禁止散落读取**：严禁在 `src/settings/manager.rs` 以外的任何地方直接读写 `settings.json` 或为此调用 `std::fs` / `serde_json`。
- **新增配置项流程**：
  1. 必须在 `src/settings/schema.rs` 对应的子结构体中添加字段，并在 `impl Default` 中提供默认值。
  2. 确保结构体带有 `#[serde(default)]` 属性。
  3. 业务代码读取配置必须通过 `SettingsManager::with(|s| ...)`，修改配置必须通过 `SettingsManager::update(|s| ...)`。

## 页面导航与布局结构 (Flutter UI)

设置页采用**全局收窄导航侧栏 + 右侧两级菜单**的设计，与全应用主界面保持一致的空间骨架：

```text
┌─────────────────┬─────────────────────────────────────────────────────────┐
│ AppNavigation   │ 设置主区域                                              │
│ Sidebar         │ ├─ 一级概览卡片页（点击卡片推入二级）                   │
│ (折叠 56 / 展开 180)│ │    [外观]   [语音]   [通用]   [数据与存储]   [关于]    │
│                 │ └─ 二级独立设置页（占满右侧区域，非半滑抽屉）           │
│                 │      [ < 返回 ] 分类标题                                │
│                 │      ├─ SettingsSection 分组卡片                        │
│                 │      │    ├─ SettingsTile / SettingsRadioGroup          │
└─────────────────┴─────────────────────────────────────────────────────────┘
```

### 交互规则
1. **两级菜单非抽屉**：点击一级分类卡片后，**直接占满右侧主内容区**进入二级独立页面，严禁使用从右侧滑出一半的 SideSheet/Drawer。
2. **返回机制**：二级页面顶部提供标准返回按钮（带左箭头）；同时绑定物理按键 `LogicalKeyboardKey.escape`，按 `ESC` 键可直接退回一级概览。一级概览页的返回按钮与 `ESC` 键退回进入设置页前的页面（来路）；若无历史路由，已连接时退回工作区，未连接时退回首页。
3. **顶栏无冲突拖拽**：桌面端窗口拖拽区域（`WindowDragRegion`）置于二级顶栏的中间空白处，不得遮挡或拦截左侧返回按钮的手势。

## 当前设置层级与分类清单

当前设置页包含 5 个一级分类，各分类包含的设置项与选项如下：

| 一级分类 | 包含设置项 | 选项与操作 |
| --- | --- | --- |
| **外观 (`appearance`)** | 主题模式 | 深色模式 (`dark`) / 浅色模式 (`light`) / 跟随系统 (`system`) |
| | 界面动效 | 开启 (`on`) / 减少动效 (`off`) / 跟随系统 (`system`) |
| | 频道栏宽度 | 当前记录的逻辑像素宽度，提供「重置宽度」按钮 |
| **语音 (`voice`)** | 发言激活方式 | 按住说话（PTT）/ 语音感应（自由发言） |
| | 按住说话快捷键 | 录制全局/应用内热键（支持清除快捷键） |
| | 电平条跟随源 | 麦克风输入 (`microphone`) / 接收音频 (`received`) |
| | 输入设备 | 系统麦克风列表选择 |
| | 输出设备 | 系统扬声器/耳机列表选择 |
| **通用 (`general`)** | 客户端昵称 | 单行文本框修改昵称（空值自动回退为默认昵称） |
| | 语言设置 | 简体中文 (`zh`) / English (`en`) / 跟随系统 (`null`) |
| **数据与存储 (`data`)** | 配置文件存储路径 | 显示并提供单键复制 `settings.json` 绝对路径 |
| | 身份与聊天历史 | 提示私钥（`identity.json`）与消息（`messages.jsonl`）的同级存储状态 |
| **关于 (`about`)** | 应用基础信息 | FlSpeak 名称、版本号、自托管声明 |
| | 许可证与开源声明 | MIT 开源协议、第三方开源代码声明链接入口 |

## 界面文案与排版约束

1. **标题 + 当前值**：每个设置项的 `SettingsTile` 标题说明「调什么」，`subtitle` 说明当前生效的取值；操作（单选、开关、录制按钮、复制按钮）放在 `trailing`。
2. **严禁解释性副文案**：不得编写「这是做什么的」废话副文案（如「选择您偏好的外观模式」等）。
3. **严禁悬停提示**：遵守全仓规则，**不得使用 `Tooltip`，不得向任何控件传入 `tooltip:`**；无障碍名称必须通过 `semanticLabel` 或 `Semantics` 提供。
4. **合规与命名**：未直接依赖源码的文件中，严禁出现模仿或对齐外部项目的名称字样。
