# AGENTS.md — 设置与配置

本规则补充根目录 [AGENTS.md](../../../AGENTS.md) 与 [lib/AGENTS.md](../../AGENTS.md)，覆盖设置模块的结构、数据持久化及交互规范。

## Settings & Configuration Rules (Rust)
- **禁止散落读取**：严禁在 `src/settings/manager.rs` 以外的任何地方直接读写 `settings.json` 或为此调用 `std::fs` / `serde_json`。
- **新增配置项流程**：
  1. 必须在 `src/settings/schema.rs` 对应的子结构体中添加字段，并在 `impl Default` 中提供默认值。
  2. 确保结构体带有 `#[serde(default)]` 属性。
  3. 业务代码读取配置必须通过 `SettingsManager::with(|s| ...)`，修改配置必须通过 `SettingsManager::update(|s| ...)`。

## 页面导航与布局结构 (Flutter UI)

设置页采用**全局收窄导航侧栏 + 右侧多级菜单**的设计，与全应用主界面保持一致的空间骨架：

```text
┌─────────────────┬─────────────────────────────────────────────────────────┐
│ AppNavigation   │ 设置主区域                                              │
│ Sidebar         │ ├─ 一级概览卡片页（点击卡片推入二级）                   │
│ (折叠 56 / 展开 180)│ │    [外观]   [通用]   [关于]                         │
│                 │ ├─ 二级独立设置页（占满右侧区域，非半滑抽屉）           │
│                 │ │    [ < 返回 ] 通用                                    │
│                 │ │    └─ 无小标题选项列表（[语音 >] [屏幕共享 >] [图片上传] [自动检查更新] [日志等级]）│
│                 │ └─ 三级独立设置页（占满右侧区域，最后一级允许小标题）   │
│                 │        [ < 返回 ] 语音 / 屏幕共享                       │
│                 │        ├─ SettingsSection 带小标题分组卡片              │
│                 │        │    ├─ SettingsTile / SettingsRadioGroup        │
└─────────────────┴─────────────────────────────────────────────────────────┘
```

### 交互规则
1. **多级菜单非抽屉**：点击分类卡片或子项入口后，**直接占满主内容区**进入对应子页面，严禁使用从右侧滑出一半的导航抽屉；每级详情通过 `prism_ui` `showExtend(forceFull: true)` 整页推入，页面自身采用 `lib/widgets/scaffold/scaffold.dart` 的 `Scaffold` 承担悬浮顶栏与状态栏退避。窄屏得到 `CardPageRoute`，宽屏得到 `FadePageRoute` 并覆盖设置侧栏；详情页不绘制设置侧栏，返回键逐级退栈，窗口跨断点时详情页保持在根导航器上，布局随断点切换。字体选择与自定义调色板分别通过 `OpenContainer`（窄屏）或 `showSheet`（桌面）打开独立选择器。
2. **面包屑式逐级返回机制**：二三级详情页通过 `Scaffold` 的 `backAction` 承接顶部返回按钮（带 `Semantics` 无障碍标签）；同时绑定物理按键 `LogicalKeyboardKey.escape`。一级概览页是导航目的地，顶栏不显示返回按钮，由宽屏全局侧栏或窄屏底部导航离开；`ESC` 与系统返回仍按退栈规则退出来路。
   - 三级页面（语音 / 屏幕共享）按返回按钮或 `ESC` 键退回二级通用页面。
   - 二级页面按返回按钮或 `ESC` 键退回一级概览页。
   - 一级概览页按 `ESC` 键或系统返回退回进入设置页前的页面（来路）；在窄屏底部导航标签根视图下退回「首页」标签；若无历史路由，已连接时退回工作区，未连接时退回首页。宽屏侧栏与窄屏底栏承担直接离开的入口。
3. **悬浮顶栏与安全区边界**：设置主区域通过 `SidebarContentInset` 剥离侧栏一侧的水平安全边距，内部滚动列表按 `context.appBarInset` 与 `MediaQuery.paddingOf(context)` 避让悬浮顶栏及系统安全区；桌面端窗口拖拽由 `WindowHeader` 与侧栏顶部避让区承担。

## 小标题与排版规则

1. **仅终末级页面允许小标题**：
   - **一级概览页**：不允许小标题，直接展示无标题卡片。
   - **非终末二级页面（「通用」）**：不允许小标题，所有跳转入口均放在无标题卡片中（`generateSection(items: [...])`），禁止出现冗余的分组小标题。
   - **终末页面（「外观」与「通用」下的「语音」、「屏幕共享」）**：**允许保留分组小标题**（`ListHeader`），且仅「外观」页面最上方放置单个 `ThemeLivePreview` 交互式实时预览卡片，不在每个选项左侧重复放对应缩略图；字体与自定义调色板交互沿用 `prism_ui` 控件。
2. **标题 + 当前值**：一级分类导航卡片与二级跳转卡片仅展示分类名称与图标，文案垂直居中，不展示深层页面内的具体配置项内容；枚举选项类设置（如语言、电平条跟随源、日志等级以及屏幕共享各项预设）统一通过 `SettingsOptionsTile` 将当前值展示（含 `PopupValueText` 模糊切换动效）置于 `trailing` 按钮中，点击后呼出依附于控件的 `PopupMenu`，并保证单行高度与普通设置项一致；开关类设置统一使用 `Switch`（经 `lib/widgets/prism.dart` 引入）。
3. **界面文案、悬停提示与无障碍名称**：遵守 [Flutter 界面文案与操作按钮约束](../../../docs/defensive-patterns/ui.md)。
4. **合规与命名**：未直接依赖源码的文件中，严禁出现模仿或对齐外部项目的名称字样。
