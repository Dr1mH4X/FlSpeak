# 清理思维链泄漏

思维链泄漏是站在书写会话视角、而不是站在仓库视角的文字：它引用只有那个会话看得到的东西，叙述「改了什么」而不是陈述「现在是什么」，或者在对一位已经离开的评审者说话。本技能给出 [docs/AGENTS.md](../../../docs/AGENTS.md) 里「叙述历史」与「CoT 泄漏」两条 slop 判据的执行细则。

## Sources of truth

- [docs/AGENTS.md](../../../docs/AGENTS.md)：写作规则与 slop checklist，本技能的上位归属。
- [.agents/notes/AGENTS.md](../../../.agents/notes/AGENTS.md)：笔记的写作规则与核查清单。
- 被审范围内的源码注释、`docs/`、`.agents/notes/`、`AGENTS.md`、`README.md`。

## 判据

对每段可疑文字问：**一个在 HEAD 上、看不到任何会话记录、PR 讨论或未提交草稿的读者，能不能解析每一个引用、验证每一句断言？** 不能，就把仍然成立的事实改写成仓库视角的表述、其余删掉。能解析只是过了本技能这一关：在陈述当前状态的文档里，可解析的变更叙事仍属于「叙述历史」。

- **会话内的决策引用**：`(decision 7)`、`(audit C2)`、`设计稿 §4.7`、阶段编号（`T4`、`P-I`）。有提交内归属就按名字与路径引用，否则删掉引用并把事实改写成独立成立。
- **PR 与分支视角**：「本 PR 增加」「上一条提交」「后续 PR」。改成已交付的机制或扩展点，延后的工作移进 `TODO` 或 issue 引用。
- **变更叙事与指代性时间戳**：「之前」「不再」「旧的 X」，以及 `v1`、`这一版`、`本轮`。改成陈述当前行为；已修复的回归写成现在时的反事实（「没有 X 时会出现 Y」）。
- **评审编排与对评审者辩解**：「评审意见是」「本笔记第 5 稿」「这样写是对的，因为……」。只留决策与依据，或写出使代码安全的不变量。
- **复述与推导过程**：控制流叙述（「先做 X，再做 Y」）、测试走查、显然分支的证明。只保留不显然的契约。
- **对冲与规划残留**：「目前应该够用」「先这样」。升级为 `TODO`/`FIXME` 或改成真实边界值。
- **书写语言残留**：中文文档里夹着的英文工作语言片段，或英文文档里夹着的未翻译中文。

## 不算泄漏

- `#147`、`TODO(名字):`、标准条款（RFC 9110 §10.1.5）、上游项目文档与上游行为在 HEAD 上可解析。
- Agent Note 与复盘里的已合并 PR 引用，以及 implemented 笔记 `## Problem` 里被允许的「修复前形态」体裁。
- 告警豁免后面被要求写的原因；被豁免的理由写错了就改对，不删。
- 现在时的反事实回归钉、带「实测」的边界值校准证据，以及运行期的新旧状态（「旧连接排空后新连接才接受」）。
- 提案笔记内部自己的 `O1`/`O2a` 编号，以及「本项目」「仓库」这类项目自称。

## 工作流步骤

1. 划定范围并明确排除项：不改 `.agents/notes/archived/`、生成物（`plugins/flspeak_ffi/lib/src/rust/**`、`lib/l10n/**`、`frb_generated.*`）、`target/`、`build/` 与 `.dart_tool/`。
2. 只读审计：先用下面的探针找候选，每个探针用一个已知正例和一个近似反例校准，再逐条按语义判断；探针只是找候选，还要无差别地读范围内文字最密的几处。
3. 按归属地修：规则性文字改 `docs/AGENTS.md` 的归属篇，笔记改对应笔记，代码注释改源码。
4. 删任何东西之前先把段落里的事实逐条列出，检查是否会把义务改成背书、把假设说成已交付、删掉真事实或丢掉证据来源。
5. 验证：重跑探针，剩下的命中应只有被认可保留的；确认每条残留引用在 HEAD 上能解析。

## 验证命令

```sh
# 会话内编号与阶段标签
grep -rnE "\((decision|ruling|audit) ?[0-9A-Z]|设计稿 ?§|plan ?§|（[A-Z][0-9]+）" docs/ core/ lib/ .agents/ --include="*.md" --include="*.rs" --include="*.dart"

# 变更叙事与指代性时间戳
grep -rnE "之前|不再|曾经|本轮|本批|这一版|第 ?[0-9]+ ?稿|目前应该|大概率" docs/ core/ lib/ .agents/ --include="*.md" --include="*.rs" --include="*.dart"

# 评审视角
grep -rnE "评审|reviewer|这条建议|按审查意见" docs/ core/ lib/ .agents/ --include="*.md" --include="*.rs" --include="*.dart"
```

## 报告要求

给出：范围、每条探针的命中数、逐条判定（保留/改写/删除）及一句理由、被删段落里事实的落地位置，以及任何拿不准而保留的原样段落。
