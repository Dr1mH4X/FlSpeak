# AGENTS.md — Decision notes

这些规则补充根 [AGENTS.md](../../AGENTS.md)，只覆盖 `.agents/notes/`。

## 什么时候写

影响结构、连接边界、并发模型、持久化格式或用户可见行为的决定，写一篇
`implemented/YYYY-MM-DD-<slug>.md`。机械改动、局部 UI 调整和纯重构不需要。

## 文件结构

```text
# 决策记录：<主题>

日期：YYYY-MM-DD
状态：已实施 / 已废弃 / 已取代

## 背景
## 决策
## 被否决的方案
## 后果
## 验证
```

- 背景写约束和触发原因，不写实现流水账。
- 决策写当前生效的规则，以及它约束哪些调用方。
- 被否决的方案写清为什么没选，避免以后重复讨论。
- 后果写收益、代价、残余风险和维护成本。
- 验证写实际跑过的检查或真实环境证据；没跑过的不要写成已验证。

已实施的记录用现在时描述已经落地的事实，不要留任务清单或“以后应该”。
当前行为以代码和 `docs/` 为准，决策记录只解释为什么。
