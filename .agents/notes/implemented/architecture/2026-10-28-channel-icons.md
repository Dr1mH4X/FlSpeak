# Agent Note: 频道图标的异步下载与连接隔离

Status: implemented

## Problem

频道自定义图标位于服务器文件区，需要协议协商和独立 TCP 连接。输入域名与 SRV 目标可能指向不同服务，图标请求又可能跨越断线或重连；等待图片数据会占用处理语音和控制命令的 actor。

## Decision

`core/session` 保存通过 `proto::client` 检查的 SRV 解析目标，所有文件传输复用它，端口来自协议协商。`FetchIcon` 在 actor 中串行协商频道 0 的 `/icon_<id>`，TCP 字节传输在 local task 中执行，不把 `Client` 协议操作交给并发任务。图标限制为 1 MiB、20 秒，下载完成后比较连接代次，旧连接的结果返回未连接错误。

文件传输对齐 JS/Go 参考实现：先发送原始 `ftkey`，随后收发明文字节，下载验证声明长度。普通上传读取器不补零，下载写入器不截断。相关音频记录仍由[双线程语音](../../implemented/architecture/2026-10-18-full-duplex-audio.md)维护，目标允许范围仍由[连接检查](../../implemented/architecture/2026-10-18-connection-boundary.md)维护。

Dart 按图标 ID 共用当前连接的 FutureProvider，并监听服务器 ID 和连接代次；换服、断线和重连使缓存失效。图片下载和解码完成后停止 M3 外框动画并保留当前形状，失败也停止动画，用户显式重试。系统减少动态效果设置使外框始终静止。服务器栏的本地图标选择保存在界面偏好中，不上传到服务器。

FFI 构造器可显式关闭音频，默认启用；真实图标的本机渲染探针关闭音频，避免仅为读取图标申请设备权限。

## Alternatives considered

**使用输入域名下载**：SRV 可指向另一台服务。真实验证中输入域名的 TCP 连接返回空数据，SRV 目标能返回完整图标。

**在 actor 内等待整张图片**：会阻塞语音和控制命令，TCP 传输本身不需要 `Client` 所有权。

**跨服务器永久缓存相同 ID**：图片是服务器文件，不能用来自另一台服务器的同 ID 文件替代。缓存只保留当前连接的数据。

**保留 AES 补零与截断**：参考实现和实际服务器使用明文文件传输，填充会改变文件内容，截断会掩盖超量数据。

## Consequences

图标解码失败或权限不足时保留可识别的占位符，重试入口使用无障碍名称。actor 的下载协商仍占用命令队列，实际 TCP 传输并发进行；断线后旧请求最多等待 20 秒，结果不会进入新连接。

## Testing

传输库的本地 TCP 测试覆盖原始密钥、非块对齐数据、截断和超量响应；会话测试覆盖精确上传字节和频道图标元数据。真实服务器探针经 actor 下载图标，Flutter 的显式本机探针通过 FFI 解码并绘制，默认测试不联网。界面测试验证动画冻结、减少动态效果、错误重试与图标持久化。
