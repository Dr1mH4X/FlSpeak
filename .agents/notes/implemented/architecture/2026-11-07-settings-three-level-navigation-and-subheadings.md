# Agent Note: 设置页三级导航与小标题收敛规范

Status: implemented

## Problem

设置模块随屏幕共享等功能的扩展逐渐膨胀，若将所有功能平铺于一级概览，导航入口繁杂，难以维持清爽的设置分类；而若将语音、屏幕共享与图片上传等所有选项平铺于二级「通用」页面并附带过多分组小标题，会导致单页垂直链路冗长且各层级小标题样式泛滥。

## Decision

- **三级层级拓扑**：
  - 一级概览：仅展示语言置顶与 4 个核心分类卡片（外观、通用、数据与存储、关于）。
  - 二级页面：作为模块跳转中枢。「通用」二级页面提供「语音」、「屏幕共享」和「图片上传」入口。
  - 三级独立子页面：在二级「通用」中点击「语音」或「屏幕共享」时，右侧主区域进入三级独立页面，完整呈现对应的详细配置。
- **小标题排版约束（全应用仅三级允许小标题）**：
  - 一级概览卡片页：禁用分组小标题，直接使用无标题卡片（`generateSection(items: [...])`）。
  - 二级页面（外观、通用、数据与存储）：一律禁用分组小标题，所有选项或跳转入口集中于无标题卡片。
  - 三级页面（通用分支下的终端页面）：作为全应用唯一允许分组小标题的层级，允许保留语义分组标题（如「按住说话」、「麦克风」、「默认画质」、「编码与网络策略」）。
- **面包屑式逐级返回与快捷键**：
  - 各级页面顶栏统一保留标准左箭头返回按钮，同时绑定物理 `ESC` 键快捷返回。
  - 三级页面按返回或 `ESC` 键退回二级通用页面；二级页面按返回或 `ESC` 键退回一级概览页；一级概览页退回进入设置前的来路。

## Alternatives considered

- **二级页面内嵌手风琴折叠卡片（ExpansionTile）**：折叠展开打乱固定视口排版，且在桌面端与已有各分类独立页面的全屏切换风格不一致。
- **允许无三级的二级页面保留小标题**：规则会分裂为「叶子节点允许」与「中间层不允许」，增加认知成本与排版不一致风险；统一规定「全应用仅三级页面允许小标题」具备全局一致性。

## Consequences

- 一级概览与二级通用保持轻量化、单一视口无滚动压力。
- 深度配置隔离至三级页面，复杂音频与视频策略按需聚焦呈现。
- 设置页需要维护 `_activeCategory` 与 `_activeGeneralSubcategory` 双状态机并协同处理物理按键与 `PopScope`。
