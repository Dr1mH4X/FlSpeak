# 0.1.12 (2026-11-08): 屏幕共享与连接指标

本版本引入基于 TS6 协议的屏幕共享与连接指标遥测，支持消息作用域隔离与跨平台双端结构化日志，并在 Windows 平台支持沉浸式标题栏。所有改动向后兼容，无需用户额外迁移。

## 新增

- 支持基于 TS6 协议的屏幕与窗口共享推流，提供窗口源选择界面并按平台约束音频采集边界（#6）。
- 支持频道内屏幕共享画面的 WebRTC 实时拉流播放与流视图垂直高度调节（#6）。
- 支持成员详情卡片展示与连接遥测，提供延迟、丢包率与带宽等网络质量指标面板（#7, #10）。
- 支持频道广播、服务器广播与私聊作用域隔离，私聊基于成员 UID 稳定追踪并支持未读角标提示。
- 支持基于 GitHub Releases 的应用版本更新检查，并在设置中提供更新状态与发布页跳转。
- 支持跨平台结构化双端日志记录，分离前端与后端日志文件，并在设置中提供数据与日志目录快捷入口（#9）。
- 支持 Windows 平台的 Mica 与 Acrylic 沉浸式标题栏、Segoe Fluent 自定义控制按钮与单实例唤醒。
- 支持服务器成员工具、信息查看与基础服务器信息编辑（#7）。

## 修复

- 修复头像下载对主音频线程的偶发阻塞，引入下载失败退避重试并在会话销毁时清理计时器（#8）。
- 修复音频编码在动态比特率（CVBR）下的传输包体积限制，避免音频帧超出网络预算导致断音（#7）。
- 修复并发遥测查询导致的请求竞争，并在指标缺失时正确呈现断点状态（#10）。
- 修复应用偏好设置在 FFI 运行时未就绪时的调用异常。

## 优化

- 统一桌面端右键上下文菜单与移动端及紧凑视口（<768px）的三点更多操作入口。
- 设置页面整合常规设置结构，提供语音与屏幕共享的三级层级导航（#6）。
- 规范化便携式发行包的解压根目录为 FlSpeak。
- 官网引入主题自适应预览、事实卡片与版本更新历史记录。

## 其他

- 确立 Flutter 界面文案与操作按钮精简约束，去除全仓悬停提示与冗余说明（#5）。
- 引入文档单物理行格式自动化校验脚本与防御模式映射表。
- 解耦 CI 流水线中的客户端快速检查作业与耗时单元测试，并将 tsclient-rs 升级至 0.2.7。
- 清理全仓自建服务器历史用词并规整测试用例目录结构。
