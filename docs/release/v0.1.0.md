# 0.1.0 (2026-10-31): 首个正式版本发布

FlSpeak 的首个正式版本，提供开源&跨平台的 TeamSpeak 客户端体验。

## 新增

- 支持 TeamSpeak 服务器连接、多身份管理与密码连接，内置 SRV 记录解析与官方域名连接过滤。
- 支持基于 Rust 双线程全双工音频传输引擎的按键发言（PTT）、麦克风静音与实时 50Hz 电平反馈（#4）。
- 支持层级频道树浏览、频道说明查看、双击加入、频道密码鉴权与成员状态实时同步（#3）。
- 支持频道聊天、私聊消息与客户端 Poke 交互，支持图片附件直传、下载与预览（#3）。
- 支持基于权限组的频道踢出与服务器踢出操作，支持频道文件列表浏览与文件下载（#3）。
- 支持基于 Material 3 的响应式布局、动态暗色主题、动效偏好配置与中英文国际化语言切换。

## 修复

- 修复连接中断后的阶梯退避重连行为，确保实时语音电平在重连后正常恢复（#4）。
- 修复频道图标传输失败时的重试机制与连接中断时的重试状态提示（#3）。
- 修复踢出成员时错误匹配目标连接的问题，以及进入频道失败时的高亮回滚逻辑（#3）。
- 修复身份编辑对话框在重命名完成时未能立即持久化到安全存储的问题。
- 修复暗色模式下应用图标与按钮前景色丢失的问题。

## 优化

- 统一频道树面板与组件视觉风格为 HairlineCard 规范，顶栏紧凑至 48px 并对齐 macOS 交通灯控件。
- 统一图标层级为语义化尺寸比例，并精简移动端触控区域与聊天输入栏交互。
- 文本格式化与 Markdown-BBCode 双向转换收归 Rust 层统一处理并支持着色渲染。
- 优化 Windows 构建在临时路径下的长路径解析，避免构建中间文件超出限制。

## 其他

- 建立 GitHub Actions 七平台矩阵构建、Android 签名与自动化 Release 发布流水线（#1）。
- 确立连接边界检查与音频数据不跨 FFI 传递的核心架构约束。
- 补齐本地多语言 arb 文案、Dart/Rust 测试套件与集成检查命令。
