# 0.1.13 (2026-11-15): 机器人开放协议、图标缓存与界面组件统一

客户端新增机器人开放身份声明与斜杠命令自动补全，加入服务器与频道图标本地缓存，界面组件切换为 prism_ui。语音采集、状态同步与浅色模式对比度一并修正，macOS 与 Windows 新增 DMG 及 Inno Setup 安装包产物，Android 最低支持版本提升至 API 26（Android 8.0）。

## 新增

- 新增机器人开放身份声明与斜杠命令协议：聊天输入框按当前频道与声明的命令前缀过滤并补全命令，成员详情与成员列表展示机器人身份标识（#11）。
- 新增服务器与频道图标本地缓存及自动服务器图标策略，默认社区服务器图标在设置 v5 自动迁移为自动获取。
- 支持运行时热切换前后端日志文件级别，屏幕共享默认参数调整为 720p、30fps、H.264 优先与降帧率策略，并接线自动检查更新偏好。
- 网络状态面板在服务端 `getconnectioninfo` 缺失自报字段时改用本地 RTT 与丢包率回退指标，应用关于卡片新增项目官网链接。
- macOS 发行包改用包含 `FlSpeak.app` 的 DMG 镜像，Windows 发行包在绿色便携压缩包之外新增 Inno Setup 安装程序。

## 修复

- 修复频道文本消息因缺少 `target_id` 导致本地回显与接收消息被按频道过滤隐藏的问题。
- 修复出站语音派发在 Session Actor 异步等待期间被阻塞的问题，改为在独立本地任务中串行发送音频事件。
- 修复音频采集短帧补零、VoicePacer 丢包与重采样混叠：采集缓冲凑满 20ms 完整帧后再执行 VAD 与 Opus 编码，先检查速率限制再编码，并将重采样器升级为 16 抽头多相加窗 sinc 实现。
- 修复语音状态（静音、闭麦、离开）高频切换时的竞态与 TeamSpeak 524 限流：本地立即生效并在 600ms 窗口内防抖合并上报，遇限流按指数退避重试，并用本地状态覆盖目录快照中的陈旧回显。
- 修复开放协议缺少 v=1 版本校验、跨对等方 ACK 冷却串扰及载荷超限问题，加入全局令牌桶限流、1024 字节载荷上限与身份公告防抖重试。
- 修复消息渲染与 BBCode 转换丢弃换行符的问题，移除控制台日志输出的边框字符。
- 修复频道树与成员列表中成员状态图标在开启屏幕共享时的排列错位。
- 修复浅色模式下输入框、容器边框对比度不足以及超椭圆裁剪丢失边框的问题。
- 将 Android `minSdk` 提升至 26，解决 `cpal` 链接 `libaaudio.so` 时的原生符号缺失问题。

## 优化

- 应用主题、表面容器、导航栏、按钮、表单弹窗、上下文菜单、加载指示器与横幅通知改为基于 `prism_ui` 实现，并从 Git 子模块切换为 pub.dev 托管依赖。
- 连接页服务器搜索框收拢为标题栏内联展开按钮，连接中的左侧徽标改为 M3 四叶草旋转动画，移除减弱动画偏好分支。
- 将 macOS、Windows、Android 与官网的多分辨率默认图标替换为虚线圆角占位图标，关于卡片复用 256px 图标资产。
- 将 `core/session` 中 6600 余行的 `actor` 模块按连接、目录、开放协议、推流、传输与语音拆分为子模块并迁移对应单元测试。

## 其他

- `tsclient-rs` 升级至 0.2.9，CI 与本地构建要求的 Flutter 版本同步升级至 3.50.0（含 Android AGP 与 Kotlin 插件升级）。
- 更新 README、界面交互规范文档与打包脚本单元测试。
