# 0.1.16 (2026-11-28): Android 屏幕共享与聊天体验改进

Android 端支持屏幕共享与常驻语音通知栏控制，聊天区加入消息多选复制与粘贴发图。语音播放在网络抖动或丢包时更平稳，未连接服务器时点击头像也会给出明确提示。

## 新增

- Android 端支持屏幕共享，并在进入语音或共享屏幕时显示常驻通知栏，可直接查看通话状态或断开连接（#17）。
- 聊天区支持多选与复制消息，并在输入框中支持直接粘贴剪贴板图片发送（#16）。
- 未连接服务器时点击主页或身份弹窗中的头像，会弹出提示告知需先连接服务器。

## 优化

- 改进语音播放的缓冲与断流平滑处理，减少网络波动或丢包时的声音卡顿与杂音。
