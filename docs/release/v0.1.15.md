# 0.1.15 (2026-11-23): 头像管理、全局热键与语音链路

补齐成员头像的上传、下载与本地缓存，修复 macOS、Windows 与 Linux 的全局按键说话。语音侧用 Rust Opus 编解码与自适应缓冲，新增降噪、VAD 预滚与 EOS 处理。

## 新增

- 新增成员头像上传、删除与下载缓存与头像持久化：客户端按 1 MiB 上限预检文件并校验图片魔数，服务端按 MD5 校验落盘，`AvatarUpdated` 使对应缓存失效；自详情、连接页身份卡与身份对话框均可打开头像对话框。
- 新增更新弹窗，展示解析后的 GitHub Release 正文，支持「不再提醒」与跳转发布页；关于页新增手动检查更新入口，使用绕过缓存的 FFI 检查。
- 新增基于 nnnoiseless 的降噪、VAD 预滚、淡入淡出包络与 EOS 包处理（#13）。
- 新增连接页按时段变化的身份问候，以当前昵称署名，并按连接历史切换回访文案。
- 关于页页脚新增 OpenProtocol 项目链接。

## 修复

- 修复 macOS、Windows 与 Linux 的全局按键说话失效，原生宿主层重新接入全局热键，设置页可配置按键并提示冲突（#14）。
- 修复屏幕共享初始同步、生命周期与观众重连：改用 tsclient-rs `Streams` 后，服务端已存在的流在进入频道时直接出现在 `SessionView.streams`，`ClientView.is_streaming` 反映发布状态，退出观看时调用 `StreamView::leave()`。流命令改为在 actor 循环外异步执行，按流 epoch 与请求/peer token 丢弃过期回调，重新加入前清理陈旧观众。
- 修复持久化的 VAD 阈值与挂起时间未送达语音引擎：新增 `SettingsManager::subscribe_audio` 与 `SessionCommand::SyncAudioSettings`，启动与修改时同步参数。
- 修复发送电平表按麦克风信号估算的问题：改用实际编码包统计 `TransmitMeter`，电平带随频道切换，来源文案改为「发送音频」。
- 修复屏幕共享选择器加载失败时缺少本地化文案，补充 `streamPickerLoadFailed`。

## 优化

- 迁移到纯 Rust `rusty-opus`，移除 `libopus` 与 CMake 构建变通；播放端按序列号自适应缓冲，加入 FEC/PLC 恢复、EOS 与淡出、播放水位控制。
- OpenProtocol 改用 tsclient-rs `OpenProtocolEngine`：单向 noreply 公告 beacon、按节奏后台发现 peer，并在 524 时停止泛洪，跨频道发现与 peer 目录变更同步进引擎。
- 会话层承接业务规则：语音标志、音频设备设置、头像与图标的重试和冷却、SDP 命令预算、频道排序、OpenProtocol 自动探测、媒体与历史上限、观众上限校验均由 Rust 处理，Dart 保持 UI、WebRTC 与 OS 桥接层。
- 连接页与工作区改用 prism_ui 控件：侧栏切换图标与动画、服务器搜索与新增入口、工作区返回按钮、添加服务器对话框统一为 `TonalButton`、`AppBarActionButton` 与矢量字形。
- 移除侧栏模糊设置与原生窗口效果通道，主题模式默认跟随系统；移除标签切换动画选项与无效的聊天回复操作。
- 屏幕共享发布端默认并发观众上限改为 `0`，即不限制。
- Rust 错误、日志与测试文案统一为英文，并通过稳定 notice code 映射到本地化界面文案。

## 其他

- 全仓从 `material.dart` 迁移到 `material_ui`，并升级 `material_ui` 1.11.1、`prism_ui` 0.1.3、`pasteboard` 0.6.2 等依赖。
- `tsclient-rs` 升至 0.3.3。
- 修正依赖迁移后的 localization 模块与 delegates 注册。
- 补充文档。
