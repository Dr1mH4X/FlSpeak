# 0.1.14 (2026-11-18): 主题定制、液态玻璃与 Android 窄屏体验优化

客户端重点改进 Android 与窄屏布局交互：重做底部三标签导航、工作区两级视图与设置整页钻取，适配状态栏安全区与系统返回键，并修复 Android 音频采集与 DNS 解析问题。同时新增主题色板、系统字体、文字缩放与液态玻璃效果（含 macOS 窗口模糊），并修复桌面端屏幕共享焦点抢占与编解码协商缺陷。

## 新增

- 新增外观与排版设置：`UiSettings` 与界面层支持种子色板、纯黑模式、色彩风格、系统字体筛选与 `0.8–1.4` 文字缩放，并提供实时主题预览。
- 新增液态玻璃材质与分级开关，macOS 窗口支持原生效能模糊与玻璃背板，宽屏侧栏与窄屏悬浮胶囊底栏接入透明材质。
- 窄屏模式新增底部三标签导航与工作区两级视图：一级展示频道树总览，点选频道以页面推入二级频道聊天与成员视图，并保留悬浮或停靠三槽语音工具栏。
- 设置多级钻取改为通过 `showExtend(forceFull: true)` 整页推入，一级概览页作为导航目的地不显示返回按钮。
- 工作区视图切换栏与详情面板标题栏改用 `GlyphSegmentedControl` 与矢量图标（媒体、文件、频道信息与成员信息）。

## 修复

- 修复 Android 端音频初始化与采集恢复：在 `MainActivity` 通过 JNI 初始化 `ndk_context`，补充运行时 `RECORD_AUDIO` 权限请求与只听回退、`aaudio:-1` 默认设备解析及断连退避恢复，并过滤 `RemoteSubmix` 等虚拟及重复内置设备（#12）。
- 修复 Android 端 DNS SRV 解析：通过 FFI 同步 `ConnectivityManager` 活跃网络 DNS（缺失时回退 `223.5.5.5` 与 `1.1.1.1`），在官方主机边界校验后直接解析为 IPv4 `SocketAddr`。
- 修复 Android 系统返回键导航：`CompactNavigationShell` 改用共享根页面避免空 `NavigatorState` 崩溃，已连接时按返回退到后台，未连接时需双击退出。
- 修复跨窄屏断点时 `BannerHost` 重建及 `NoticeCenter` 重复弹窗问题，并修正 macOS 顶栏下横幅通知的顶部内边距。
- 修复桌面端窗口屏幕共享抢占焦点问题：Linux 与 Windows 禁用采集器 `focus_window`（Windows 启用无边框 WGC），macOS 在启动采集期间抑制应用激活。
- 修复屏幕共享编解码协商与画质参数：保留 RTX/RED/ULPFEC/FlexFEC 伴随编解码器，Darwin 端仅向 `preferVideoCodecOnTransceiver` 传入主视频编解码器，过滤冗余本地 ICE 候选，修复应答后候选异步刷新，并支持预览缩放动态调整分辨率，720p/1080p 预设码率调整为 5000/8000 kbps。
- 修复聊天输入框发送消息时丢失焦点或被异步上传覆盖新草稿的问题：发送开始即清空输入与附件，仅在发送失败时恢复草稿。
- 修复 macOS 正式版沙盒缺少 `network.server` 权限导致无法绑定本地 UDP 套接字的问题，以及 Windows 强制包含头文件前缺少 `_CRT_SECURE_NO_WARNINGS` 宏定义的编译报错。

## 优化

- 迁移 FlClash 悬浮 `Scaffold` 与状态栏安全区退避方案，统一连接页、设置页与窄屏工作区顶栏及挖孔屏适配。
- 优化工作区与连接页渲染性能，补充细粒度状态订阅、`RepaintBoundary` 隔离与后台空闲降载。

## 其他

- 升级 `material_ui`、`go_router`、`talker` 等 Flutter/Dart 依赖，更新主题、液态玻璃与界面性能规范文档。
- Android 调试包构建支持单调递增构建号与来源标签，支持编译期通过 `APP_DISPLAY_VERSION` 覆盖展示版本而不影响更新检查版本号。
