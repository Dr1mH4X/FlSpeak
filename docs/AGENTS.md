# docs/AGENTS.md

`docs/` 面向使用者与维护者，`.agents/` 面向编码代理。两边的规则以 `.agents/` 为准，
面向人的说明放这里。

## 本目录

| 文件 | 内容 |
| --- | --- |
| `architecture.md` | 分层、数据流、一次连接的完整时序 |
| `connection-boundary.md` | 自托管连接边界、SRV/图片/文件传输的最终检查 |
| `audio.md` | 双线程语音链路、codec 跟随、jitter/VAD 与已知限制 |
| `backend.md` | 语音/同步/重连/身份/历史/文件传输的后端收口设计 |
| `images.md` | TS6 图片真实格式、连接边界、富文本渲染与发送设计 |
| `ci-cd.md` | CI 作业、发布矩阵、打包产物与已知简化 |

## 写文档的规矩

- 说清“为什么”，不重复代码已经说清的东西。
- 命令要能直接复制执行，写明工作目录。
- 未完成的部分要显式标注“尚未接线”，不要写成已完成。
- 改了行为就同步改文档；`docs/` 与 `.agents/commands.md` 的命令必须一致。
