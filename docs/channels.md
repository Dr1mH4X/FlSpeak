# 频道访问、权限组与文件

## 密码频道

双击频道或使用加入菜单时，先提交不带密码的移动请求。服务器接受时直接进入；只有结构化的频道密码错误（781）才打开密码框。密码错误保留输入供修改，取消或失败恢复原频道高亮。权限不足、频道已满与断线不会被当作密码问题。

密码在 Rust 中按语音协议要求转换为 SHA-1/Base64，再写入 `cpw`。频道文件目录与传输协商使用相同转换。密码仅保存在当前弹窗或文件页的内存中，不写入偏好与聊天历史。弹窗核对服务器和连接代次，避免切服后误用频道 id。

是否免密进入由服务器决定；频道有锁标志也会先尝试免密。拥有服务器授予的忽略频道密码权限时，可以直接进入，界面不按用户昵称或权限组名称推断身份。

## 简单权限管理

成员菜单提供服务器组与频道组成员资格管理。有效权限来自服务器推送的 `notifyclientneededpermissions`，权限名称和 id 使用该服务器的 `permissionlist` 映射。未报告、已撤销或查询失败均按未知处理；没有正数成员添加或移除权限时，管理菜单置灰。

每个组按服务器报告的所需添加/移除数值权限启用操作。服务器默认组、模板和 Query 组不作为可添加的服务器组；频道组以替换当前组的方式设置，需要同时具备移除旧组和添加新组的权限。界面不提供任意权限值编辑、封禁或服务器配置修改。

提交时 actor 重新按 UID 查找在线成员并核对身份，读取最新有效权限并检查组要求，频道组还核对目标频道。成员换频道、掉线或权限撤销后拒绝过期操作；最终修改继续由服务器校验。权限变化事件使界面重新读取操作权限。权限名称映射仅在当前连接复用；组定义最多缓存 30 秒，服务端拒绝修改时立即失效，重连清空全部缓存。

## 频道文件

工作区“文件”页签读取当前选中频道的文件目录，支持进入子目录、返回上级、输入频道密码与下载。远端路径只能是无父级跳转的绝对频道路径；服务端文件名不能包含路径分隔符。文件目录、传输协商与权限操作都在会话 actor 中串行执行，只有 TCP 字节传输独立运行。

传输主机使用通过连接检查的 SRV 会话目标，端口由服务器协商。下载先写同目录随机临时文件，严格校验声明字节数并同步到磁盘，完成后发布为下载结果；Rust 下载接口拒绝覆盖已有目标；桌面导出遵循系统保存对话框的覆盖确认。失败或连接代次变化时取消下载并清理临时文件。网络连接及无进展超时由协议传输层处理。

桌面端在完整下载后提供系统保存对话框；macOS 通过用户选中文件的读写授权保存。Android 10 及以上通过 MediaStore 保存到下载目录的 FlSpeak 子目录，无需全盘存储权限；旧版 Android 保存到应用的外部下载目录。取消导出时删除本地暂存结果。下载由会话控制器持有，切换聊天或文件页不会丢弃已请求的下载；断线仍取消尚未完成的网络传输。

文件传输仍使用 TeamSpeak 的明文 TCP 协议。此功能只访问自托管频道文件，不下载官方 myTeamSpeak 附件。普通文件上传 UI、断点续传和长期传输历史尚未接线。
