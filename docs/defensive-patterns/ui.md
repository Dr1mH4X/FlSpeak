# Flutter 界面文案与操作按钮

## 操作按钮

- 按钮文字已清楚表达操作时，只显示按钮文字；不在按钮下方或旁侧增加重复的说明文字、说明性标签或副标题，也不通过 `subtitle` 等组件属性重复解释操作。
- 错误做法：在「添加并连接」按钮下方写「添加服务器并立即连接」。正确做法：只显示「添加并连接」按钮。
- 全仓不添加悬停提示。Flutter 不引入 `Tooltip`，也不给 `IconButton` 等控件传入 `tooltip:`；图标按钮的无障碍名称通过 `semanticLabel` 或 `Semantics` 提供。`MaterialLocalizations` 中的 `*Tooltip` 只作为标准语义文案使用。

## 允许的说明文案

- 破坏性或不可逆操作需要明确的安全警告时，可以显示警告。
- 按钮不可用且用户需要知道原因时，可以说明禁用原因。
- 表单存在复杂校验限制时，可以在对应输入框旁显示校验提示；校验提示不放在操作按钮旁。

## 杜绝技术实现细节外溢

- 界面与弹窗面向终端用户，不是开发者的调试控制台或架构备忘录。
- 严禁在界面、说明文本或提示中阐述底层探测机制（如后台定时轮询、采样频率）、命令限流等待、协议库底层能力缺失或实现妥协理由。
- 界面只陈述用户关心的核心领域事实（如网络状态、连接延迟、失败原因与下一步安全操作）。

## 视觉系统与布局约束

- 表面层级、超椭圆圆角、字阶、按压反馈与设置行规范必须遵守 [Flutter 界面设计规范](../subsystems/ui-design.md)。
- 优先使用 `prism` 组件：标准交互控件、表面容器与反馈原语一律通过 [lib/widgets/prism.dart](../../lib/widgets/prism.dart) 选用 `prism_ui` 实现（上游包已提供但未转出时先在桥接层补充导出）；引入 `package:flutter/material.dart` 时 `hide` 同名冲突的 Material 控件，不在 `lib/` 手写重复控件或回退使用 Material 默认控件。
- 禁止使用 `Tooltip` / `tooltip:`；禁止在按钮或自绘卡片上恢复 `0.94` 缩放按压；禁止在普通卡片/设置行外围恢复描边或图标色块填充。
