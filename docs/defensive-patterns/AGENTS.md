# AGENTS.md — 编码反面准则

本文档目录定义 FlSpeak 仓库的编码反模式清单与正确替代做法：每篇针对特定领域，给出反面模式（错误做法）与规范模式（正确做法）。改并发与会话 actor、音频双线程、连接边界相关代码前，先通读对应子篇、[../architecture.md](../architecture.md) 与相关决策记录。

## 目录索引

- [最高原则与通用代码规范](general.md)：第一性原则、FAILFAST、YAGNI、DRY、警告消除与类型安全。
- [连接边界与网络安全](connection.md)：官方主机清单、单一出口检查与放宽限制流程。
- [音频线程与编解码](audio.md)：双线程无锁环形缓冲区、音频帧零跨越 FFI 边界。
- [审查与调试反面](review.md)：审查原则、问题诊断与事实陈述规范。

## 目录规则与约束

- 每篇文档聚焦一个特定主题或故障类别，采用「错误做法」与「正确做法」对比结构。
- 严禁在反面准则中展开长篇历史叙事或架构时序（架构时序归 `docs/architecture.md`，子系统规范归 `docs/subsystems/`）。
- 一事实一归属：本目录属于审阅强制规则（Review），只记录判定规则与反模式，具体子系统契约与接口留给对应子系统。
